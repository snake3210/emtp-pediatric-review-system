# EMT-P 小兒、新生兒與婦產急症 (PALS / NRP / OB) 視覺化戰情複習系統

🔗 **線上直接刷題網址（GitHub Pages）**：
👉 **[https://snake3210.github.io/emtp-pediatric-review-system/](https://snake3210.github.io/emtp-pediatric-review-system/)**

本專案採用 **`universal-exam-review-builder`（萬用考題拆解與視覺化戰情複習系統建置器）** 全域技能建置，完整收錄 **108～114 年度衛生福利部高級救護技術員（EMT-P）甄試筆試** 中所有關於 **新生兒復甦術（NRP）、小兒高級救命術（PALS）、小兒內外傷與發展評估、以及急產接生與妊娠外傷急症** 共 **60 題** 歷屆試題。

## 📂 專案核心檔案說明

- **[`index.html`](index.html)**：雙主題（🌙 深色戰情室 / ☀️ 明亮護眼）響應式單頁應用程式（SPA），搭配本地 [`exam_data.js`](exam_data.js)、[`tailwind.min.js`](tailwind.min.js) 與 [`images/108-73.png`](images/108-73.png) 運作。
- **[`EMTP_婦兒與新生兒急救_終極單一獨立版.html`](EMTP_婦兒與新生兒急救_終極單一獨立版.html)**：**100% 免連網單一檔案封裝版**（已內嵌 Tailwind 離線引擎、60 題完整四維度解析與 Base64 圖譜），可直接傳送至手機（iOS / Android）、iPad 或電腦離線刷題。
- **[`exam_questions.json`](exam_questions.json)**：60 題結構化四維度逆向工程題庫（含 `algorithm_path`、`key_triggers`、`confusion_trap`、`guideline_check`）。
- **[`subject_config.json`](subject_config.json)**：6 大領域弱點雷達分類與 5 大考前衝刺速查表（Cheat Sheet Modal）設定檔。
